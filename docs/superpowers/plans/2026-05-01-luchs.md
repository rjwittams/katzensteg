# Luchs Implementation Plan

> **For agentic workers:** REQUIRED: Use superpowers:subagent-driven-development (if subagents available) or superpowers:executing-plans to implement this plan. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build `luchs` as a local visual fragment viewer with separate renderer and presenter backends, using SDL as the first presenter and native WebView as the next renderer.

**Architecture:** Keep `tools/luchs/` independent of Katzensteg internals for now. Renderer backends produce raw frames; presenter backends consume raw frames. The current concrete presenter is SDL, which keeps a normal window fallback and lets Katzensteg capture through its SDL adapter. A future presenter can call a proper app-facing Katzensteg core API once external framebuffer batch/embed and non-preload runtime initialization exist.

**Tech Stack:** Zig 0.15.2, SDL2, macOS `WKWebView` first for native HTML rendering, later WebKitGTK on Linux, future `libkatzensteg-core` app-facing presenter.
